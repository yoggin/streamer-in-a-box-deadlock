# streamer in a box, Deadlock edition

Records your Deadlock matches and cuts the highlights for you.

**Download:** the newest `streamer-in-a-box-deadlock-setup.exe` is under
[Releases](https://github.com/yoggin/streamer-in-a-box-deadlock/releases/latest).

Run it, say yes to the Steam account it finds, turn recording on, play.
Windows may show an "unknown publisher" notice the first time: choose *More info*, then *Run anyway*.
Recordings go to `Videos\streamer in a box`. Uninstalling never deletes them.

Installed copies check this page for updates once a day and offer to install them.
Each release carries a `.sha256` file with the installer's fingerprint and a `latest.json` the app reads.
